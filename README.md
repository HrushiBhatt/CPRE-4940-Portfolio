# Portfolio

A single-page portfolio built with React and Vite.

## Run it

```bash
npm install
npm run dev     # start the local dev server
npm test        # check that every section renders
npm run build   # production build in dist/
```

## Add your content

All of the text lives in `src/content.js`.
PDFs and project images go in the `public/` folder and are linked from `content.js` as `/file-name`.
